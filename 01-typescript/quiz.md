# Quiz TypeScript

1. Quelle est la différence entre `let` et `const` ?
2. À quoi sert une interface ?
3. Pourquoi éviter le type `any` ?
4. Que fait `filter` sur un tableau ?
5. Que signifie `Task[]` ?

## Réponses

1. `const` ne peut pas être réaffecté ; `let` peut l'être.
2. Elle décrit la structure attendue d'un objet.
3. Il désactive une partie de la sécurité apportée par TypeScript.
4. Il retourne un nouveau tableau contenant seulement les éléments qui respectent une condition.
5. Un tableau contenant des objets de type `Task`.
