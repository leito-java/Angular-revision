# Quiz — Tests unitaires

1. Quelle différence existe-t-il entre un test unitaire et un test d'intégration ?
2. À quoi sert `TestBed` ?
3. Que signifie Arrange, Act, Assert ?
4. Pourquoi tester le DOM d'un composant ?
5. Pourquoi une couverture de 100 % ne garantit-elle pas l'absence de bugs ?

## Réponses courtes

1. Le test unitaire cible une petite unité ; l'intégration vérifie plusieurs parties ensemble.
2. Il prépare l'environnement Angular nécessaire au composant testé.
3. Préparer les données, effectuer l'action, vérifier le résultat.
4. Un composant associe une classe et un template ; le comportement visible fait partie de son contrat.
5. La couverture mesure le code exécuté, pas la qualité ni la pertinence des assertions.
