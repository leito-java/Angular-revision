# Exercice — Tester la suppression

Ajoutez un test dans `app.component.spec.ts` qui :

1. vérifie qu'une tâche est visible ;
2. clique sur son bouton « Supprimer » ;
3. vérifie que la tâche n'est plus affichée.

Utilisez la méthode Arrange, Act, Assert et testez le résultat visible plutôt qu'une méthode privée.
