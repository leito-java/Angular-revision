# Parcours Angular pour débutants

Ce parcours s'adresse à une personne qui ne connaît pas encore Angular. Il présente une seule idée importante à la fois, puis l'utilise dans le gestionnaire de tâches.

La documentation officielle Angular est notre source de vérité. Ce parcours ne la remplace pas : il la reformule en français simple, sélectionne l'essentiel et ajoute de la pratique.

> Références vérifiées avec Angular 22 le 23 août 2026. Consultez toujours les liens officiels pour vérifier les évolutions du framework.

## Comment travailler

Pour chaque étape :

1. Lisez l'objectif et l'explication.
2. Retapez le petit exemple sans copier-coller.
3. Faites l'exercice.
4. Vérifiez les critères « Je peux continuer si… ».
5. Expliquez la notion avec vos propres mots.
