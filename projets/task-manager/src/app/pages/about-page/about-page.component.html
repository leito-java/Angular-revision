À propos du laboratoire

Une application conçue pour apprendre en construisant.

TaskFlow relie chaque notion Angular à une fonctionnalité que vous pouvez voir, tester et expliquer.
01

Comprendre

Chaque fichier contient des commentaires ciblés et la documentation explique le rôle des API Angular.

02

Pratiquer

Les exercices vous demandent de reconstruire une petite fonctionnalité avant de lire sa correction.

03

Vérifier

Les tests automatisés et la CI empêchent une nouvelle étape de casser les acquis précédents.

Le chemin d’une navigation

  1. 1L’utilisateur clique sur un routerLink.
  2. 2Le routeur cherche le chemin dans app.routes.ts.
  3. 3Le composant de page est chargé dans router-outlet.
  4. 4Le TaskStore fournit le même état à toutes les pages.
