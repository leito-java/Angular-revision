# Atelier Angular débutant

Cet atelier contient six versions exécutables. Chaque version introduit une seule notion principale.

## Installation unique

```cmd
cd "C:\Users\EL GORCH\Documents\Codex\2026-08-22\bo\outputs\angular-revision\projets\atelier-debutant"
npm install
```

## Lancer une étape

| Étape | Commande | Notion |
|---|---|---|
| 01 | `npm run start:01` | Premier composant |
| 02 | `npm run start:02` | Templates et événements |
| 03 | `npm run start:03` | Découpage en composants |
| 04 | `npm run start:04` | Inputs et outputs |
| 05 | `npm run start:05` | Signals et état réactif |
| 06 | `npm run start:06` | Reactive Forms |

Après le démarrage, ouvrez `http://localhost:4200`.

Arrêtez le serveur avec `Ctrl+C` avant de lancer une autre étape.

## Méthode recommandée

1. Lisez le chapitre correspondant dans `parcours-debutant`.
2. Lancez l'étape.
3. Repérez dans le code la notion expliquée.
4. Modifiez une valeur et observez le navigateur.
5. Faites l'exercice du chapitre.

La version 07 est le projet complet [`task-manager`](../task-manager/README.md).
